# Security Policy

## Reporting a Vulnerability

We take all security vulnerabilities seriously. Thank you for improving the security of our open source software.

Please **do not** report security vulnerabilities through public GitHub issues. 

Instead, please report them directly via [GitHub's private vulnerability reporting](https://github.com/pwurbs/wuflow/security/advisories/new) feature. 

If for any reason you cannot use the private vulnerability reporting feature, please look for contact information on the GitHub profile page of the maintainers.

We will try to respond as soon as possible to acknowledge your report and outline the next steps.
